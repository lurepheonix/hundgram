## New
- Updated to Inugram base v46
- [About › Updates](tg://settings/inu/about) can switch between plugins and pluginless builds
- Translator: rich messages translate inline while preserving formatting

## Improved
- Plugin details collapse long permission scope lists and let you expand them
- Material 3 profile actions and settings icons have more consistent spacing and alignment
- [Behavior › Decode internationalized URLs](tg://settings/inu/decode-idn-urls) shows readable addresses by default, existing opt-outs are kept

## Fixed
- Unread reactions could return after being read, counters could drift and reactions could flicker during message updates
- Notification avatars could disappear after Android evicted their cached images
- Sticker pack Edit buttons could ignore slower taps or inherit the Create button's long-press action
- Profile actions could overlap after changing Material style, and Add post could flash before Posts loaded
- Reopening the photo editor could leave outlines around blurred areas
- Photo viewer could crash when minimized
- Albums forwarded to Saved Messages could use the wrong layout before server confirmation
- Web previews were missed for links embedded in formatted text
- Emoji and sticker panel controls stayed translucent when Power Saving disabled blur
- Deleted bots could show the wrong bottom action
- Classic UI bot menu button alignment was incorrect
- Plugin author usernames could not be tapped, and emoji icons loaded by document ID could stay blank

## Plugins
- Translation providers can translate rich messages while preserving their formatting
- TL vector views support array methods such as map, slice, push and pop
- unsafe.xposed detects LSPosed conflicts and rejects hooks safely
- Timeout logs identify the stalled RPC, send, translation or update callback
