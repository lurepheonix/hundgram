> ‼️ This release contains an important plugins API security fix.
> It is recommended to update if you use plugins.

## New
- Updated to Inugram base v49 (Telegram 13.0.3 with a new experimental voice recorder and assorted fixes)
- Stock experimental voice and round recorder settings are now visible in release builds
- [Look & Feel › Customize items](tg://settings/inu/drawer-menu-order) for the navigation drawer: reorder, hide, add dividers and mini apps
- [Privacy & Security › Resolve trackable redirects](tg://settings/inu/resolve-trackable-redirects): expand share links (TikTok, SoundCloud, map links and more) when pasting and opening
- Web preview replacements can also be applied when pasting links ([Behavior › Web preview replacements](tg://settings/inu/web-preview-replacements))
- "Send a gift" in the profile menu, optional "Gift" action button ([User profile › Show "Gift" action button](tg://settings/inu/show-profile-gift-button))
- Power Saving › Effects in chats: disable animated avatars separately from video autoplay

## Improved
- Look & Feel rework: Material 3 toggles, classic UI options and navigation settings
- Admin log edit diffs are easier to read
- URL cleaning prefers the bundled ruleset when it is newer than the downloaded one
- Database migrations on update show a loading screen

## Fixed
- Sent messages move into server order once confirmed, matching what recipients see
- Unread reactions: server answers dropping your just-sent reaction are corrected from local state
- No "sent" tick before the server actually confirms the message
- Android 16 expanded dark theme no longer force-inverts the app
- Update bar with bottom tabs disabled
- Low-resolution avatar in Settings
- Settings camera button clipped on some screen densities
- Untranslated "Chats" title in the chats list
- Reduced motion message menu glitches
- Material 3 sections styling on the "Bots with biometry access" page

## Plugins
- Important security fix in the plugins API, updating is recommended if you use plugins
- Plugin repositories: Telegram channels to install plugins from and receive updates through
- Plugin descriptions support Telegram markdown
- Memory usage on the plugin info page and the `inu memory` CLI command (`-w` to keep sampling)
- `inu.sqlite`: private per-plugin database behind the `sqlite` grant (50 MB by default, raise with e.g. `sqlite(200mb)`)
- Bundled assets: import images, fonts, audio and other binary files directly, read lazily with no JS heap cost via `inu.assets.get(name)`
- Viewing source of plugins with very long string literals is much faster
- Plugins with inlined PNGs are no longer falsely flagged as obfuscated
- Fixed adaptive icons as plugin icons
