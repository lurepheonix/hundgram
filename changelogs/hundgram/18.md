## New
- Updated to Inugram base v53 (Telegram 13.2.1)
- [Look & Feel › Hide on scroll](tg://settings/inu/bottom-tabs-hide-on-scroll): hide bottom tabs while scrolling the chat list
- [Dialogs list › Show tabs at the bottom](tg://settings/inu/folder-tabs-at-bottom): move folder tabs to the bottom of the chat list and forward picker
- [Messages › Compact mode](tg://settings/inu/compact-mode): separate compact mode for channels, groups and private chats
- [Privacy & Security › Don't autoplay widgets](tg://settings/inu/dont-autoplay-widgets): widget messages show a placeholder and only start after a tap
- Classic UI: option to revert screen headers to the pre-12.6 style
- Send inline bot results as regular messages (without "via @bot"), with a toggle in the send menu of the media preview
- "Send without pack" in the sticker preview menu
- Bulletin with the error code when the server keeps failing to deliver a message

## Improved
- Settings pages use the new glass header
- Profile scroll snap and reduce motion settings now also apply to the settings page
- More contrast in the dialog list with the Monet theme
- Spoilered link preview thumbnails are covered in the reply bar, pinned bar and reply quotes
- tg://nya and tg://woof use custom emoji

## Fixed
- New 13.2 glass panels ignoring the Lite Mode blur setting
- Connecting to proxies with an IPv6 address or a hostname resolving to IPv6
- Auto video quality sticking to the lowest track, and "Auto" in the quality menu not showing the actual quality
- Downloads stalling forever after a repeated file reference expiry
- Mentions marked as read when the read position passes them
- Inline bots blocked by the stickers permission instead of the inline one
- Monet theme in the chat list after switching themes
- Dialogs FAB hiding after the archive snaps back
- Attach camera preview stuck after discarding a photo
- Drawings on HD photos shrinking into a corner on low-end devices
- Crash on Android 17 when system fonts change with a custom app or monospace font
- Crash updating a folder title after leaving the chat list

## Plugins
- Plugin crashes show the full error in a sheet, and crashes that happened in the background are announced
