## New
- Updated to Inugram base v51
- [Behavior › Extra text actions](tg://settings/inu/selection-process-text): "Web search" and actions from other apps (e.g. "Ask Claude") in the message text selection menu
- "Show hidden messages" in the chat menu, to see messages from blocked/hidden users until the chat is closed
- Drawer: "New channel" item

## Improved
- Sleek bottom tabs no longer need the material style, the two are mutually exclusive (Appearance › Navigation)
- Link cleaning: Ozon redirects, `?a` in Twitter links, resolving redirects no longer blocks sending
- Video editing (mute, quality, crop) for AV1 and other formats with a device decoder, original quality sends any video unchanged
- Icon packs: sharper SVG rendering, animated icon replacements
- Extra bottom padding under stickers is always removed
- "Disable glass glare" covers the new QR and lockscreen buttons
- Drawer closes on back instead of exiting the app

## Fixed
- MP4 documents resent as videos
- Own channel posts showing a text signature with author profiles enabled
- Reactions with equal counts swapping places, unread reactions counter stuck after the server reports a read
- Replies to inaccessible chats showing truncated text
- Disappearing HD photos in secret chats showing only the thumbnail
- Height animation when opening reply/forward options
- Rotating in the avatar editor
- Emoji panel crash on a cancelled tab drag
- Drawer "New message" and "New group" items swapped
- Classic UI: call bar in dialogs, player panel offsets in shared media, folder strip ripple in the forward picker
- Legacy Camera2 flag kept after switching to the new recorder
- AdGuard lists with plain wildcard rules
- Memory leaks in the emoji panel

## Plugins
- Message filtering/rewriting api
- Custom text entities
- Translation providers selectable by long-tapping "Translate" in the message menu
- `.inu.js` files installable from global search and shared media
- `tg://inurepo` deeplink to add a plugins repo
- Regexes matched with QuickJS libregexp everywhere
